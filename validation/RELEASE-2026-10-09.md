# Local application release verification

## Passed

- 15 automated tests, including all-signal event routing with controlled detections, calibration math, configured machine activity, temporal escalation, output files and SQLite history persistence.
- Upload-only Streamlit integration with real inference through all enabled models; rerunning the same upload reuses its result.
- Real warehouse clip processed with five detection models, encoded to H.264 MP4 and successfully decoded again. Reviewed `release-frame.jpg` visually.
- Full PPE, fall and fire/smoke weights loaded with the expected class maps; exact hashes and revisions recorded in `models/manifest.json`.

## Evidence limits

No labeled industrial benchmark is available. These tests verify execution and event logic, not accuracy. The upstream fall sample is an annotated four-scene collage: no fall passed the configured 0.65 threshold; a cropped scene yielded fallen confidence 0.208 at a lower diagnostic threshold. The threshold was not lowered just to make this sample pass. A spurious forklift was also detected in the collage. This is evidence that site-specific validation and likely fine-tuning are still needed.

Smoke/fire positive recall and full-PPE recall have not been established. Camera calibration and machine profiles are implemented but are disabled without actual site configuration. No live machine telemetry connection is configured. The review score is explicitly heuristic and uncalibrated.

The software is a local upload-and-review application. It is not a certified hazard detection system or a replacement for factory safety controls.
